Campos vetoriais e fluxos

Considere os campos constantes no espaço de parâmetros T²:

X = λ₁ ∂/∂θ + λ₂ ∂/∂φ
Y = −λ₂ ∂/∂θ + λ₁ ∂/∂φ

Os campos induzidos na superfície são obtidos pelo diferencial da parametrização:

f*X = λ₁ fθ + λ₂ fφ
f*Y = −λ₂ fθ + λ₁ fφ

Curvas integrais

Para o ponto inicial (θ₀, φ₀), os fluxos no espaço de parâmetros são:

ΦX(t) = (θ₀ + λ₁t, φ₀ + λ₂t) mod 2π
ΦY(t) = (θ₀ − λ₂t, φ₀ + λ₁t) mod 2π

As curvas desenhadas são as imagens desses fluxos pelo mapa f. A animação percorre simultaneamente as duas órbitas.
